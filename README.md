# Computer Vision & Image Processing Project

A computer vision project developed during the Aygaz Image Processing Bootcamp, demonstrating image filtering, edge detection, and feature extraction pipelines.

## Overview

This repository contains practical image processing implementations. It covers image transformation techniques, color space conversions, thresholding, contour detection, and object detection logic using OpenCV.

## Features

- Image Preprocessing: Grayscale conversion, Gaussian blurring, and histogram equalization.
- Edge & Contour Detection: Canny edge detection and contour extraction.
- Feature Extraction: Bounding box annotation and feature mask generation.

## Dependencies

- Python 3.8+
- OpenCV (opencv-python)
- NumPy
- Matplotlib

## Execution Instructions

1. Install requirements:
   pip install -r requirements.txt

2. Open and run the Jupyter notebook:
   jupyter lab
